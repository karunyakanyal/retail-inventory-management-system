# Retail Inventory Management System (RIMS) Documentation

## Overview
Enterprise Retail Inventory Management System built with Spring Boot 3, React + Vite, MySQL / H2, Docker, Kubernetes, and Jenkins.

## Architecture
- **backend**: Spring Boot 3 REST API (Java 21, JPA, Spring Security Basic + BCrypt, H2/MySQL)
- **frontend**: React + Vite SPA
- **k8s**: Kubernetes deployment, service, configmap, and ingress manifests
- **docs**: System architecture, API documentation, and agile release notes
